# Planned operations exercises

These recovery procedures are hypotheses to rehearse once the application exists. Save actual results; do not mark an incident exercise complete from reading it.

## Extra lap

**Diagnose:** Find repeated event IDs and close successive times.

**Recover:** Apply the agreed exclusion ruling.

**Prove recovery:** Replayed lap count matches the marshal sheet.

## Unstable tie

**Diagnose:** Compare equal timestamps and event IDs.

**Recover:** Implement the documented secondary sort.

**Prove recovery:** Reverse-input test gives identical ranks.

## Missing entrant

**Diagnose:** Compare aliases with the heat roster.

**Recover:** Correct the fixture or assign a reviewed ruling.

**Prove recovery:** Unmatched list is empty or explained.

## Stale standings

**Diagnose:** Compare the latest ruling with the view revision.

**Recover:** Rebuild standings from the ledger.

**Prove recovery:** Export digest reflects the ruling.
