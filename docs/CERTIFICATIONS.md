# Certification practice map

| Certification track | Skills this project practices | Evidence to produce |
| --- | --- | --- |
| AWS Certified Developer – Associate | Event-triggered processing and retry handling | Demonstrate equal digests after duplicate deliveries in a local handler test. |
| CompTIA Data+ | Data quality and reconciliation | Publish a hand-scored heat and a discrepancy report. |

These mappings are our proposed practice alignment. They do not claim complete exam coverage, vendor endorsement, exam eligibility, or a passing score. Compare the actual evidence you produce with the current official objectives; mark uncovered objectives for separate study.

## How to study with this repo

For each lab, explain why the design works, execute a failure, diagnose it from evidence, repair it, and demonstrate recovery. Record the official objective you associate with that work in [the evidence template](../evidence/TEMPLATE.md). A service name in an architecture diagram is not hands-on evidence.

## Source currency

The [official reference list](REFERENCES.md) was reviewed on November 16, 2026 for naming and broad skill alignment. Exam versions and objectives change. AWS Developer - Associate is transitioning versions around this date, so this series uses certification names rather than prescribing an exam code. Choose your actual exam version from the official provider when booking. CompTIA and Linux mappings here are broad practice suggestions; verify their current objectives separately.

Keep answers and troubleshooting notes in your own words. Do not store exam dumps or confidential exam content in the repository.
